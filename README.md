# Text Expander – Snippets & Shortcuts

Free offline Chrome text expander for reusable text snippets, typing shortcuts, email templates and productivity. Type a shortcut such as `/gmail`, then press **Space** to insert your saved content.

## Features
- Keyboard shortcut text expansion in supported website input fields and rich-text editors.
- Snippet library with folders and search.
- Insert text templates, canned responses and email replies.
- Dynamic placeholders: `{date}`, `{time}`, `{datetime}`, `{url}`, `{domain}`.
- Local JSON import/export backup.
- No account, subscription or cloud API required.

## Install
Download the ZIP from [GitHub Releases](https://github.com/shayanmila/textexpand/releases), extract it, open `chrome://extensions`, enable Developer mode, select **Load unpacked**, and choose the extracted folder containing `manifest.json`. Set Site access to On all sites and refresh already-open pages.

## Limitations
Some protected pages, native apps, and specialized editors cannot be supported. Installing from GitHub does not automatically list this extension in the Chrome Web Store.
