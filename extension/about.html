About Text Expander

Free offline text expander for Chrome: create reusable snippets and insert them by typing a shortcut and pressing Space.

Developer

Developer website

Privacy

Snippets are stored locally in your browser using Chrome extension storage. This extension does not send snippet content to a developer server, use analytics, or require an account.

To recognize shortcuts, the extension checks text being typed in editable website fields. It does not intentionally process password fields. Site access is required for text expansion to work on websites.

Export your snippets before uninstalling or replacing the extension, as local data may be lost.

How to use

Create a snippet in Manage Snippets, set a shortcut such as /gmail, then type it in a supported website text field and press Space.

Chrome internal pages, some protected websites and native desktop applications are not supported.
